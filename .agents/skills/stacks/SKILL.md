# Stack-Specific Coding Standards

This directory contains coding standards for supported technology stacks.

## Available Stacks

- `nextjs.md` — Next.js 15 + TypeScript + Supabase + Vercel
- `laravel.md` — Laravel 12 + PHP + MySQL + cPanel
- `django.md` — Django + DRF + Celery + Redis
- `express.md` — Express.js + TypeScript + Node
- `fastapi.md` — FastAPI + Python + SQLAlchemy
- `react-native.md` — React Native + Expo Router + Zustand

## Usage

Copy the relevant stack file into your project root as your coding standards reference. If no stack file matches your project, fall back to the universal standards in the root `CODING_STANDARDS.md`.
