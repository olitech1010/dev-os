# Vendored skill licenses

License texts for the third-party skills bundled in `.agents/skills/`.
`THIRD_PARTY_NOTICES.md` at the repository root maps each skill to its upstream
and license; these files hold the texts those licenses require to travel with
the material.

| File | Covers |
|---|---|
| `MIT-upstreams.txt` | the MIT-licensed skills, with each upstream's copyright line |
| `Apache-2.0.txt` | the Apache-2.0 skills (license text; see §4 for the attribution terms) |
| `CC-BY-4.0.txt` | the `backend-dev-guidelines` prose content |

Two licenses live with their own skill rather than here, because they are
specific to it:

- `.agents/skills/security-review/LICENSE` — CC BY-SA 4.0 (OWASP Cheat Sheet
  Series). This one is copyleft: that material is not under the Dev-OS MIT
  license. See the root `LICENSE`.
- `.agents/skills/imagegen/LICENSE.txt` and
  `.agents/skills/skill-creator/LICENSE.txt` — Apache-2.0, as shipped upstream.
