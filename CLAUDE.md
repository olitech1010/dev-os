## ServBay MCP Usage

Use the ServBay MCP server whenever a task touches the local ServBay development environment.

Call ServBay MCP tools for:
- checking service status and logs
- diagnosing local website/domain/HTTPS issues
- checking ports
- managing ServBay packages and versions
- inspecting databases and local environment state
- creating or restoring backups

Prefer read-only inspection first. Ask before write/destructive operations and follow the confirmation_token flow.
