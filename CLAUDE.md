## ServBay MCP Usage

Use the ServBay MCP server whenever a task touches the local ServBay development environment.

Call ServBay MCP tools for:
- checking service status and logs
- diagnosing local website/domain/HTTPS issues
- checking ports
- managing ServBay packages and versions
- inspecting databases and local environment state
- creating or restoring backups

Prefer read-only inspection first. Ask before write/destructive operations and follow the confirmation_token flow.

## Dev-OS — Multi-Agent Engineering OS

This repository IS the Dev-OS source. When working here:

- Read `.agents/AGENTS.md` for the agent roster, workflow protocols, and the Hard Rules before making changes.
- The npm package is `dev-os` (bin: `devos`); the CLI lives in `bin/devos.js` and must stay zero-dependency.
- `.claude/commands/` and `.claude/agents/` in target projects are GENERATED by `devos init` from `.agents/commands/` and `.agents/agents/` — edit the `.agents/` sources, never generated output.
- Run `npm test` (scripts/smoke-test.js) after changing the CLI or `.agents/` content.
- No emojis in first-party files; status output uses `[ OK ]` / `[ WARN ]` / `[ FAIL ]` tags.
